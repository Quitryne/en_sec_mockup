📈 핵심 출제 경향 분석
5가지 키 인사이트로 본 시험의 성격
①
어법(Grammar) 비중이 절대적으로 높음
선택형 7문항(19~25번) + 서답형 3문항 = 약 34점. 어법 정밀도가 변별의 핵심.
②
교과서 본문 활용도 높음
1~7번(약 22점)이 교과서 본문에서 출제. 본문 정독 + 어법 분석이 필수.
③
시사(현재성) 지문 대거 등장
19~25번 어법 문제 모두가 2024~2025 한국 시사 이슈. 영자신문 헤드라인 학습이 유리.
④
어휘·문맥 추론 문제 변별
단순 동의어가 아닌 문맥 속 의미 차이(face vs avoid, significant vs minimal)로 변별.
⑤
고난도 변별 문항 식별
17번(글 순서, 3.4점), 25번(어법 2개, 3.5점), 서답 3·5번이 1·2등급을 가르는 핵심.
⚡ 집중 출제 어법 포인트
우선순위별로 정리한 핵심 어법 11가지
  • 분사 vs 동사 — located / dated / held / watching (Van Gogh 단원)
  • 수동태 — was reported, are burning, was held
  • 현재완료 수동 — have been recreated
  • so ~ that 구문 — so funny that I couldn't stop laughing
  • no longer 위치 — should no longer be viewed as separate from
  • to부정사 vs 동명사 — to assist / having carried
  • 주어-동사 수일치 — depend → depends, have → has
  • 분사구문 — offering / spreading
  • 관계대명사 — which / what 구별
  • 동사형 일치 — continue → continued, entering → enter
  • The number of + 단수동사 — 시사 지문 단골 함정

학생 지도 시 우선순위별 액션 가이드
A. 본문 학습 전략
  • Resilience 단원 — 핵심 표현(adapt to / face / overcome / immune system 비유)을 빈칸·삽입 문제 형태로 반복 훈련.
  • Matthew Syed 단원 — (가)~(마) 어법 포인트 모두 분석 + 밑줄 의미 함축(B "I've had enough", D "the boy likes the idea") 별도 연습.
  • Van Gogh 단원 — 분사 구문(located/dated/held/watching) 수동·능동 구별 집중 훈련.

📝 학생 학습 지침
고득점을 위한 체크리스트 + 함정 회피 전략
✅ 반드시 해야 할 것
  • 교과서 본문 3개 단원 완벽 암기 수준 (Resilience, Matthew Syed, Van Gogh & Arles)
  • 본문 속 모든 분사·관계사·수동태에 형광펜 표시하고 어법 설명할 수 있어야 함
  • so~that, no longer, several of them have been p.p. 등 구문 직접 작문 연습
  • 영자신문 헤드라인 기사 주 2~3편 읽기 (특히 Korea 관련)
  • 함축 의미 문제(밑줄 친 표현 의미 파악) 유형 별도 연습
⚠️ 흔한 실수 포인트
  • 분사로 써야 할 자리에 동사 원형/과거형을 그대로 둠 (was located → located)
  • the number of + 복수명사 + 단수동사 (depend → depends)
  • 시제 불일치 (continue → continued, has → had)
  • to부정사 능동/수동 구별 (to entering → to enter)
  • 서답형 추가 단어 사용 금지 규정 위반 (보기에 없는 be동사 추가)
  • 서답형 철자 오류 추가 감점 주의 (recreated, viewed, maintaining)
⏱️
시험 시간 배분 권장

🔮 다음 시험(기말) 예상 출제 방향
출제자 패턴 기반 5가지 예측
  • 어법 비중은 동일하거나 더 높을 가능성 — 출제자가 어법 변별을 선호함이 명확
  • 2학기 본문 + 시사 지문 결합 형태 유지 예상
  • 서답형 어순 배열(보기 단어 활용)은 고정 출제 유형으로 굳어진 것으로 보임
  • 밑줄 친 부분 함축 의미 추론 유형 지속 등장 예상
  • 시사 지문은 시험 직전 1~2개월 한국 뉴스 위주 선별 가능성 → 시험 직전 기사 챙길 것
